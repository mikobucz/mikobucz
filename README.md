### About me

I am a software engineering student working with Rust, TypeScript, JavaScript, and Python.

- I am building [sci_globe](https://github.com/mikobucz/sci_globe), a knowledge globe in Rust and WebAssembly where the layout emerges from connections between research papers.
- I co-built [InternHelp](https://github.com/Projekt-ITDays/InternHelp) with a Google mentor for AGH University IT Days, using NestJS, Angular, LangGraph, and MongoDB.
- I built a personal offline-first PWA and macOS dashboard backed by SQLite for tracking daily nutrition, micronutrients against RDA/DRI thresholds, weight, calories burned, and expenses.

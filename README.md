### About me

Software Engineering student building things across **systems programming**, **full-stack TypeScript**, and **AI agent workflows** — from Rust + WebAssembly physics simulations to multi-agent career engines.

- 🔭 Currently building **[sci_globe](https://github.com/mikobucz/sci_globe)** — a knowledge globe in **Rust & WebAssembly** where spatial layout emerges bottom-up from connections between research papers.
- 🤖 Co-building **[InternHelp](https://github.com/Projekt-ITDays/InternHelp)** — an autonomous career roadmap engine powered by **NestJS, Angular, LangGraph & MongoDB** (built with a Google mentor for AGH University IT Days).
- 🔍 Exploring compilers, parsers, and internals (currently digging into **[sqlglot](https://github.com/tobymao/sqlglot)**).
